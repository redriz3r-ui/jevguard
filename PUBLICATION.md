# Publication notes

jevguard is being preserved as a public-source candidate.

Current scope: Typed runtime guard, deterministic policy, fake sandbox and local mock demonstration, with a dependency-free test command.

Preparation still required: Add a license and keep the mock-only limitation prominent: this version does not evaluate the actual Jev classifier. Do not describe it as a validated security product.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
